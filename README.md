## About This Repository

**BML (Build • Learn • Master)** is a comprehensive AI and Machine Learning learning repository covering the complete modern AI ecosystem.

This repository starts with the foundations required for AI and progresses through:

**Programming → Mathematics → Data Science → Machine Learning → Deep Learning → NLP → Computer Vision → Transformers → Generative AI → LLMs → RAG → Fine-Tuning → AI Agents → Reinforcement Learning → MLOps → AI Engineering → Production AI**

The focus is on **understanding concepts, implementing algorithms, building projects, and deploying real-world AI systems**.
